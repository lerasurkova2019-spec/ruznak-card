# Цифровая визитка Ирины Романовой — РУЗНАК

## Как открыть
1. Откройте папку `ruznak-card` в Visual Studio Code.
2. Откройте `index.html` в браузере или запустите через расширение Live Server.
3. Для публикации разместите содержимое этой папки в корне репозитория GitHub и включите Settings → Pages → Deploy from a branch → main / (root).

## Где менять данные
- Тексты, телефоны, ссылки: `index.html`.
- Цвета и оформление: `css/style.css`.
- Переключение темы, языков и скачивание контакта: `js/script.js`.
- Фотография: `images/irina-romanova.png`.
- Будущие PDF: папка `files/`. Когда материалы будут готовы, добавьте их туда и вставьте ссылки в раздел «Ссылки и материалы» файла `index.html`.

**Примечание:** Ссылка «Записаться на встречу» ведёт на указанный Telegram. Логотип компании в шапке представлен декоративной буквой «Р», поскольку отдельный файл логотипа не предоставлен.
